# 🛍️ Neo Commerce | Premium Landing Page

A high-performance, visually striking single-page e-commerce template designed with a modern "Aurora Cyber-Luxury" aesthetic. Built entirely with vanilla web technologies, this project prioritizes elegant micro-interactions, flawless responsiveness, and zero-dependency frontend architecture.

## ✨ Features

*   **Aurora Design System**: A custom dark theme featuring deep space backgrounds, electric cyan/purple gradient accents, glowing shadows, and sleek glassmorphic UI elements.
*   **Interactive Hero Carousel**: A custom auto-rotating slider equipped with Instagram-style progress indicator bars. It fully supports mouse-drag and mobile touch-swipe mechanics, all written in clean Vanilla JavaScript.
*   **Smart Navigation (ScrollSpy)**: Implements the `IntersectionObserver` API to track the user's scroll position and dynamically update the active state of the navigation menu.
*   **Pure CSS Animations**: Smooth, hardware-accelerated CSS transitions, staggered fade-in entrance animations, and engaging 3D-tilt hover effects on product cards.
*   **Fully Responsive**: Built mobile-first using modern CSS Grid and Flexbox to ensure perfect layouts across all device sizes.
*   **Zero Frontend Dependencies**: No React, no jQuery, no Bootstrap. Just highly optimized HTML5, CSS3, and Vanilla JavaScript.

## 🛠️ Tech Stack

*   **Frontend**: HTML5, CSS3 (Custom Variables, Grid/Flexbox), Vanilla JavaScript (ES6+)
*   **Backend/Server**: Node.js, Express (Lightweight static file server)
*   **Typography**: Google Fonts (Poppins & Inter)

## 🚀 Getting Started

This project includes a lightweight Express server for local development and deployment.

### Prerequisites
*   [Node.js](https://nodejs.org/) (v14 or higher)

### Installation

1.  **Clone the repository** (if applicable) or download the source files.
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Start the local development server**:
    ```bash
    npm start
    ```
4.  **View the application**: Open your browser and navigate to `http://localhost:3000`.

## 🎨 Design Philosophy

This project actively moves away from generic, bulky UI frameworks in favor of a bespoke, handcrafted aesthetic. 
*   **Performance first**: By eliminating heavy JavaScript libraries, the time-to-interactive (TTI) is virtually instantaneous.
*   **Accessibility**: High-contrast typography, semantic HTML tags, and accessible form inputs ensure a highly usable experience.
