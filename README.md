# 🛍️ Neo Commerce | Premium Landing Page

A high-performance, visually striking single-page e-commerce landing page designed with a modern "Aurora Cyber-Luxury" aesthetic. Built entirely with pure HTML5 and CSS3, this project prioritizes elegant micro-interactions, flawless responsiveness, and zero external dependencies.

## ✨ Features

*   **Aurora Design System**: A custom dark theme featuring deep space backgrounds, electric cyan/purple gradient accents, glowing shadows, and sleek glassmorphic UI elements.
*   **Pure CSS Animations**: Smooth, hardware-accelerated CSS transitions, staggered fade-in entrance animations, and engaging hover effects on product cards.
*   **Pure CSS UI Components**: Clean layouts, custom buttons, and interactive states built entirely without scripting.
*   **Fully Responsive**: Built mobile-first using modern CSS Grid and Flexbox to ensure seamless layouts across all device sizes.
*   **Zero Dependencies**: No JavaScript frameworks, no CSS libraries. Just clean, optimized HTML5 and CSS3.

## 🛠️ Tech Stack

*   **Markup**: HTML5 (Semantic Structure)
*   **Styling**: CSS3 (Custom Variables, Flexbox, CSS Grid, Transitions/Keyframes)
*   **Typography**: Google Fonts (Poppins & Inter)

## 🚀 Getting Started

No build steps, package managers, or local servers required.

### Quick Start

1. **Download or clone** the repository.
2. **Open the project**: Double-click `index.html` or open it directly in any modern web browser.
3. *(Optional)* Use an extension like **Live Server** in VS Code for live-reloading during development.
